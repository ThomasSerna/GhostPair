## Changes

- Choose **Show host panel** in the extension menu or Settings. The choice is saved between sessions. **Hide panel** hides the on-page panel; reopen it from the GhostPair extension menu.
- Switch between **Visual only** and **Live control** from the host panel's **Interaction mode** selector, synchronized with the extension menu.
- Each session still starts in **Visual only**. Hiding the panel preserves interaction, animation, and remote-control settings.
- Protocol version 4 and extension permissions remain unchanged.
