## What changed in 0.7.0

- **English and Spanish:** The extension automatically uses the browser's language, including regional English and Spanish variants. Other browser languages fall back to English. There is no language prompt during installation or first use.
- **Your language preference:** Open **Settings → Language** to choose **Automatic**, **English** or **Español**. Changes save on this installation and update the popup, session viewer, notices and shared-page controls without restarting a session. Each participant keeps their own language.
- **Browser integration:** Extension descriptions and the session keyboard shortcut description follow the browser language. Chrome and Edge manage their own permission prompts and capture indicators.

## Compatibility and limits

- Saved identities, connection settings and preview preferences remain intact. Existing installations start in Automatic until a language is selected manually.
- Manifest V3 permissions and the official Heroku signaling origin are unchanged. Current source uses protocol `6` as both its latest version and supported baseline. Product versions can differ while retaining that wire baseline; unsupported protocols are rejected without downgrading authentication. Protocol-4/5 installations require a one-time extension rebuild/reload and signaling deployment. Language preferences are local and are not sent to the other participant.
- The public website also supports automatic English/Spanish and an independent saved header preference. Its interface, installation guide and interactive demo controls are translated; editable demo values and authentic static extension exports retain their contents.
- Shared website content, page titles, addresses and copied text in real sessions are not translated.
