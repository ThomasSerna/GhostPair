# GhostPair 0.6.0

- Start with **Share my tab** or **Join a session**, with a clearer connection code and password flow.
- Manage shared tabs, page control, **Preview changes** and **Full control** from a simpler extension menu.
- Keep clipboard sharing and **Interaction feedback** in **Advanced options**, with preferences saved automatically.
- Use the ready-to-use **GhostPair server**, or configure a **Custom server** with the existing validation and permission checks.
- See clearer connection, control and clipboard status in the shared viewer and page controls.
- Session behavior, tab limits, capture permissions, security and protocol version 4 remain unchanged.
