GhostPair privacy

What GhostPair does

GhostPair lets two people share and control authorized browser tabs. The host starts each session, chooses a password, and authorizes each captured tab locally. The host can pause or end the session. Anyone with the host's address and password can join while that session is available.

Information used

The extension transmits video of the active authorized tab, titles and addresses of tabs in the shared window, and page interaction instructions to the authorized participant. New tabs require host approval before their content is shared. If both participants enable synchronization, the extension also transmits new Windows clipboard text, including text copied in other applications. Files, clipboard images, and audio are not included.

Signaling uses a random installation identifier, an owner credential, a session password, and technical WebRTC connection data. The signaling server and STUN process IP addresses; a remote participant can also learn the other participant's IP address.

How information travels

Video, control, and clipboard text travel directly through encrypted WebRTC connections. They do not pass through signaling and are not relayed by TURN. Production signaling uses HTTPS/WSS. The signaling operator authenticates pairing and temporarily receives the session password for verification.

What is retained

The extension retains installation identity and settings locally. The server retains the installation identifier and owner-credential hash to preserve the fixed address. The session password verifier is held temporarily in memory. The implementation does not retain recordings, clipboard history, or message bodies in logs.

The operator must specify retention periods for identities, infrastructure logs, and backups here, together with instructions for requesting deletion of registered data.

User controls

You can stop the session from GhostPair or with its configured shortcut. You can withdraw control, release an authorized tab, or disable clipboard synchronization. Native browser capture indicators remain visible, and permissions can be revoked in the browser. A canceled capture requires fresh local authorization. Closing or reloading the guest page ends its connection. Uninstalling the extension or clearing its data removes the local identity; it does not automatically delete an existing server registration.

Limited use

Information received from Chrome APIs is used only for the collaboration features described here, in accordance with the Chrome Web Store User Data Policy and its Limited Use requirements. GhostPair does not include advertising or sell data. A remote participant receives content for the authorized session; choose participants you trust.
