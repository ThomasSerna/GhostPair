GET STARTED

Download & install.

Install GhostPair in both browsers.

Get the latest release ↗

  1. Choose your browser

    Download the Chrome or Edge ZIP from the release's Assets. Choose the extension package, rather than the source code archive.

  2. Extract the ZIP

    Keep the extracted folder in a permanent location on your computer.

  3. Load the extension

    Open chrome://extensions or edge://extensions. Turn on Developer mode, select Load unpacked, and choose the folder containing manifest.json.

FROM YOUR TAB TO THEIRS

How it works.

01

Host a session

Open GhostPair on a web page, choose a password, approve sharing, and select Share current tab. Share your GhostPair address and password with your guest.

02

Join and collaborate

The guest selects Connect to a host and enters those details. Sessions start in Visual only: clicks and typing are previews. The host can switch to Live control for real page interactions.

03

Keep control

Approve additional tabs individually. Pause sharing, withdraw control, or end the session whenever you need. Scrolling, navigation, and tab management remain live in both modes.

Video and interactions travel directly over WebRTC. Clipboard text sync is optional and requires both participants. Browser tabs only; no audio or desktop sharing. Some networks cannot establish a direct connection.
